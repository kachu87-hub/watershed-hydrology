# 集水區水文分析工具

單一 HTML 網頁工具：點選河道控制點，以 DEM 自動劃設集水區，依 CODiS 雨量站做徐昇多邊形加權，進行頻率分析、雨型設計、修正三角型單位歷線 / 合理化公式與土石流流量計算，並可產出 HTML 報告。

## 使用方式
1. 開啟網頁，於地圖載入 DEM 後，在藍色河道上點擊控制點。
2. 於「步驟 2 & 3」上傳各雨量站的 CODiS Excel（日資料 / 時資料）。
3. 檢視成果，按「產出報告」。

## 說明
- 雨量站僅採用中央氣象署 CODiS 測站（含撤銷站，報告中會標示）。
- 所有資料均在使用者瀏覽器內處理，不會上傳至伺服器。
- 需可連網以讀取 DEM 圖磚與底圖。
- 計算成果僅供規劃參考，正式設計請由專業技師複核。
